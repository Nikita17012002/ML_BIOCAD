# ML_BIOCAD

## Проект: Анализ мутаций белков и предсказание ΔΔG

## Описание проекта
Проект анализирует влияние точечных мутаций на стабильность белковых комплексов, используя:
- **ESM-2** (Evolutionary Scale Modeling) для генерации векторных представлений белков
- **Методы машинного оубчения** для классификации мутаций по знаку изменения свободной энергии (ΔΔG)
- **Биоинформатические пакеты** для обработки PDB-файлов и мутационных данных

## Скрипты
- `Analysis_dataset_and_create_model.ipynb` содержит все шаги решения задачи
- `esm_embedding.py` содержит дополнительный скрипт для генерации векторных представлений аминокислотных последовательностей
